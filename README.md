# Тренировки

Личный трекер силовых тренировок — PWA для iPhone. Всё хранится и считается на телефоне
(IndexedDB), сервер нужен только чтобы отдать статические файлы. Работает без интернета.

## Поставить на iPhone

1. Открыть адрес приложения в **Safari**.
2. «Поделиться» → «На экран „Домой“».
3. Запускать с иконки — так у приложения своё хранилище, которое Safari не чистит.

Адрес менять нельзя: данные привязаны к нему. Перед переездом — «Настройки → Сохранить копию»,
на новом адресе — «Восстановить из файла».

## Поменять программу

Вся программа — в [js/program.js](js/program.js), три части:

- `EXERCISES` — упражнения: название, стартовый вес, шаг, план подходов и повторений.
  `mult: 2` — вес вводится на одну руку, а работают обе (тоннаж ×2), `bw: true` — собственный вес (вводится доп. вес).
- `GROUPS` — группы мышц и их упражнения. Все обязательные, порядок внутри группы можно менять на ходу.
- `DAYS` — дни сплита и порядок групп по умолчанию (перед стартом его можно поменять).

`id` (ключи) менять нельзя — к ним привязана история. Названия, веса, подходы — можно.
`npm test` проверит, что в программе нет опечаток в id.

## Выложить обновление

1. Поднять `VERSION` в [sw.js](sw.js) — иначе телефон продолжит показывать старую версию из кэша.
2. Если добавился новый файл — дописать его в `ASSETS` там же.
3. Залить файлы на хостинг. Телефон подхватит обновление при следующем запуске с интернетом
   и предложит перезапустить приложение.

## Разработка

```sh
npm run serve   # http://localhost:8080 — на localhost service worker отключён, кэша нет
npm test        # тесты расчётов (Node 20+)
```

Сборки нет: обычные ES-модули.

- `js/stats.js` — все расчёты (тоннаж, дельты, «сколько осталось», подстановка веса) — чистые функции с тестами
- `js/screens/workout.js` — экран тренировки
- `js/input.js` — три варианта панели ввода подхода (A степперы, B быстрый, C колёса)
- `js/store.js`, `js/db.js` — данные в памяти и IndexedDB
- `js/backup.js` — резервная копия в JSON
